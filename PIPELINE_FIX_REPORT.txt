========================================
WHAT WAS CHANGED
========================================

The monolithic 1130-line pipeline.py was decomposed into 12 focused modules
following the LOCAL-FIRST principle. AI is now used only when local methods
cannot handle the task. Key changes:

1. LOCAL-FIRST EXTRACTION: Digital PDFs are processed entirely locally via
   pymupdf4llm + regex parsing. AI is only called when local parsing fails.
2. OCR ADAPTER: Added Tesseract/PaddleOCR/EasyOCR support for scanned pages.
3. IMAGE COMPRESSION: Images are now resized (max 1024px) and converted to
   JPEG before sending to AI, reducing token cost by ~70-80%.
4. TOKEN LIMITS: Every AI call now has max_tokens configured.
5. STRUCTURED SCHEMA: Questions use a consistent Question dataclass with
   fields for type, metadata, answer keys, validation status, etc.
6. ANSWER KEY SUPPORT: Questions now support correct_answer / correct_answers.
7. QUESTION TYPE DETECTION: Detects Pilihan Ganda, MCMA, Benar/Salah,
   Tepat/Tidak Tepat, Kategori, and Essay types.
8. VALIDATION LAYER: Questions are validated after extraction and after AI
   generation. Invalid items are marked for human review.
9. FILE-BASED CACHING: Extraction, solution, and variation results are cached
   to avoid redundant AI calls.
10. CONFIGURATION MODULE: All hardcoded values moved to config.py with
    environment variable overrides.

========================================
REMAINING LIMITATIONS
========================================

1. NO MATH VALIDATION: Generated answers are not algebraically verified.
   SymPy integration would require additional dependency.

2. NO ASYNC PROCESSING: Streamlit UI still blocks during AI calls.
   Full Celery/Redis would require infrastructure changes.

3. NO MULTI-TENANT: Single-user design. No per-client API keys,
   rate limiting, or isolation.

4. BASIC OCR: OCR adapter is implemented but quality varies by PDF.
   Complex layouts (two-column, tables) may still fail.

5. NO ANSWER KEY EXTRACTION: Answer keys are generated by AI (draft)
   rather than extracted from the source PDF.

6. LIMITED QUESTION TYPE SUPPORT: Benar/Salah, Kategori, and
   Tepat/Tidak Tepat are detected but variation generation
   may not preserve the format correctly.

7. NO DOCX EXPORT FOR COMPLEX TYPES: Statement tables and category
   matching tables are not fully rendered in the DOCX export.
