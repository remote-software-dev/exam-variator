========================================
KNOWN GAPS AND NEXT STEPS
========================================

1. NO WEBSOCKET FOR PROGRESS: Frontend polls every 3s. WebSocket push
   would reduce latency and server load.

2. NO AUTH: Single-user design. No JWT, no per-client API keys.

3. NO ASYNC DB: Backend uses synchronous SQLAlchemy. For production
   with PostgreSQL, switch to asyncpg + SQLAlchemy async.

4. NO CELERY: BackgroundTasks work for single-server. For horizontal
   scaling, swap to Celery + Redis.

5. NO DOCX EXPORT FOR COMPLEX TYPES: Statement tables and category
   matching are not fully rendered in DOCX.

6. NO ANSWER KEY EXTRACTION: Answer keys are AI-generated drafts.

7. NO HUMAN REVIEW DASHBOARD: needs_human_review flag is set but
   no dedicated review UI.

8. FRONTEND DOES NOT HANDLE PAGINATION: Job list and questions show
   all items. For large datasets, add pagination.

9. NO DOCKER: No Dockerfile or docker-compose yet.

10. NO CI/CD: No GitHub Actions or deployment config.
